**Дата:** 2024-11-27
**Статус:** ✅ Реализовано (MVP)
**Версия:** 1.0.0

---

## 🎯 Что это?

**AI Selector Engine** - система для автоматического поиска элементов на странице по описанию на естественном языке, с поддержкой self-healing.

### Ключевые возможности:

1. ✅ **Intent-based селекторы** - находит элементы по описанию ("primary CTA under hero title")
2. ✅ **Self-healing** - автоматически восстанавливает сломанные селекторы
3. ✅ **Приоритет устойчивости** - getByRole > getByLabel > getByText > data-testid > CSS > XPath
4. ✅ **Fast & Accurate режимы** - DOM-only (1-2 сек) или DOM + Vision (3-5 сек)
5. ✅ **Кэширование** - SHA256 кэш с multi-tenant support
6. ✅ **Hybrid intent parsing** - правила + AI fallback

## 🚀 Использование

### 1. Базовое использование (Resolve Selector)

```typescript
import { AISelectorEngine, DOMNodeExtractor } from '@/services/ai-selector';

// Extract DOM nodes
const nodes = await DOMNodeExtractor.extractNodes(page, {
  mode: 'fast',
  visibleOnly: true,
  interactiveOnly: true,
});

// Resolve selector from intent
const result = await AISelectorEngine.resolve({
  intent: "primary CTA under hero title",
  dom: await page.content(),
  nodes,
  metadata: {
    url: page.url(),
    viewport: { width: 1920, height: 1080 },
    projectId: 'my-project',
  },
  mode: 'fast', // or 'accurate' with screenshot
});

if (result.success && result.selectedNode) {
  console.log('Selector:', result.selectedNode.primarySelector);
  console.log('Confidence:', result.selectedNode.confidence);

  // Use selector
  await page.locator(result.selectedNode.primarySelector).click();
}
```

### 2. Self-Healing (автоматически в CommandExecutor)

```typescript
// Self-healing включен по умолчанию
const executor = new CommandExecutor(page, {
  selfHealingEnabled: true,
  metadata: {
    url: page.url(),
    projectId: 'my-project',
  },
});

// Если селектор сломается, автоматически попробует восстановить
await executor.executeCommand({
  action: 'click',
  selector: '.old-button-class', // Может не работать
  description: 'click primary CTA', // Intent для healing
});
```

### 3. Manual Self-Healing

```typescript
import { SelfHealingService } from '@/services/ai-selector';

const healingResult = await SelfHealingService.healSelector({
  oldSelector: '.btn-primary',
  intent: 'click primary CTA button',
  page,
  errorMessage: 'Element not found',
  metadata: {
    url: page.url(),
    projectId: 'my-project',
  },
  mode: 'fast',
});

if (healingResult.success && healingResult.newSelector) {
  console.log('Old:', healingResult.oldSelector);
  console.log('New:', healingResult.newSelector);
  console.log('What changed:', healingResult.diff.what_changed);
  console.log('Confidence:', healingResult.diff.confidence);
  console.log('Auto-applied:', healingResult.autoApplied);
}
```

## 📋 Intent Parsing

### Hybrid подход (приоритет: правила → AI)

**Вариант A: Есть action.description (быстро, дешево)**

```typescript
// Action description используется как intent
action.description = "click login button";
// → Intent: "click login button"
// → Парсится правилами (0.1 сек)
```

**Вариант B: Нет action.description (AI fallback)**

```typescript
// Генерируется из goal + context
goal = "Test login functionality";
// → Intent generated by AI: "primary login button"
// → Парсится AI (1-2 сек)
```

### Примеры intent:

```typescript
// ✅ Простые (правила)
"click login button"
"fill email field"
"select country from dropdown"
"check terms checkbox"
"primary CTA under hero title"

// ✅ Сложные (AI)
"first login button"
"email input in login form"
"submit button under signup form"
```

## 🎨 Selector Types (приоритет)

1. **`getByRole`** (0.90) - Самый устойчивый
   ```typescript
   getByRole('button', {name: 'Login'})
   ```

2. **`getByLabel`** (0.85) - Для inputs
   ```typescript
   getByLabel('Email address')
   ```

3. **`getByText`** (0.75) - Для кнопок/ссылок
   ```typescript
   getByText('Sign up')
   ```

4. **`data-testid`** (0.95) - Если есть
   ```typescript
   [data-testid="login-button"]
   ```

5. **`css`** (0.60-0.85) - Fallback
   ```typescript
   #login-btn
   .btn-primary
   ```

6. **`xpath`** (0.45-0.50) - Last resort
   ```typescript
   //button[contains(text(), "Login")]
   ```

## 💾 Кэширование

### Cache Key Structure

```typescript
SHA256(
  projectId + '|' +
  intent_normalized + '|' +
  domHash + '|' +
  viewport + '|' +
  model_version + '|' +
  engine_version
)
```

### Пример:

```
projectId: "my-project"
intent: "click login button" → normalized: "click login button"
domHash: "a1b2c3d4e5f6g7h8"
viewport: "1920x1080"
model_version: "gpt-4o-2024-11-20"
engine_version: "1.0.0"

→ Cache key: "ai-selector:7f8e9a0b1c2d3e4f..."
```

### TTL: 1 час (3600 секунд)
