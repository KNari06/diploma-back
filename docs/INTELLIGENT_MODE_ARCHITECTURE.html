1. Обзор системы

Intelligent Mode — это полностью автоматизированная система тестирования веб-приложений, использующая AI для анализа страниц, генерации действий и принятия решений.

+-------------------------------------------------------------------------------+ | INTELLIGENT TEST ORCHESTRATOR | | (Главный координатор всего процесса) | +------------------------------------------+--------------------------------------+ | +----------------------------------+----------------------------------+ | | | v v v +------------------+ +----------------------------+ +------------------------+ | IntelligentPage | | ContextualAction | | CommandExecutor | | Analyzer | | Generator | | (Исполнитель команд) | | (Анализ страницы) | | (Генератор действий) | | | +----------+--------+ +------------+---------------+ +-------------+----------+ | | | v v v +------------------+ +----------------------------+ +------------------------+ | DOM Analysis | | AI (GPT-4o / GPT-4o-mini) | | getSmartLocator() | | Vision Analysis | | Action Generation | | Self-Healing | | SPA Load Wait | | Decision Making | | Smart Wait | +------------------+ +----------------------------+ +------------------------+

Основной цикл работы:

analyze → understand → generate → pre-check → execute → post-check → validate → decide → repeat

Улучшения:

  • ✅ MainLoopService — выделен отдельный сервис для цикла
  • ✅ Logic Analysis — новый этап понимания логики страницы
  • ✅ Error Collection — сбор ошибок на всех этапах
  • ✅ Cancellation Support — поддержка отмены теста
  • ✅ Pattern Detection — обнаружение проблемных паттернов

2. Файлы и их роли

1. IntelligentTestOrchestrator

Файл: intelligent-test-orchestrator.ts

Роль: Главный координатор всего процесса тестирования

Ключевые методы:

  • execute() — запуск теста
  • abort() — отмена выполнения теста
  • Использует MainLoopService для основного цикла

Новые возможности:

  • ✅ Поддержка отмены теста (cancellation)
  • ✅ Error Collector для сбора ошибок (console, network, UI)
  • ✅ Graph Builder для визуализации теста
  • ✅ Cost Manager для контроля бюджета

1.5. MainLoopService

Файл: main-loop.service.ts

Роль: Основной цикл тестирования (выделен из Orchestrator)

Ключевые методы:

  • execute() — выполнение основного цикла
  • handleDecision() — обработка решений (continue/stop/retry/skip/wait_for_user)
  • handleSkipNavigation() — навигация при skip

Логика цикла:

  • Проверка отмены перед каждой итерацией
  • Проверка лимитов (pages, duration, errors)
  • Обнаружение пустых страниц (consecutive empty pages)
  • Обнаружение циклов (URL-based cycle detection)
  • Обнаружение проблемных паттернов (ActionPatternDetector)

2. IntelligentPageAnalyzer

Файл: intelligent-page-analyzer.ts

Роль: Анализ веб-страниц с помощью AI

Режимы анализа:

Режим Vision DOM Скорость Точность
fast ❌ ✅ Быстро Средняя
balanced ✅ (1 раз) ✅ Средне Высокая
full ✅ (всегда) ✅ Медленно Максимальная

Что анализирует:

  • Тип страницы (login, dashboard, checkout, etc.)
  • Доступные элементы (кнопки, формы, ссылки)
  • Модальные окна (cookie banners, popups)
  • Состояние SPA (ждёт полную загрузку)
  • ✅ Logic Analysis (GPT-4o-mini) — определяет requiredActions, possibleActions, skipHints, navigationActions
  • ✅ AI Selector Enhancement — улучшает DOM селекторы с помощью AI Selector Engine
  • ✅ Error Signals — собирает ошибки консоли, сети, UI

Новые поля в PageContext:

  • requiredActions — действия, обязательные перед основными
  • possibleActions — все возможные действия
  • skipHints — подсказки о том, когда/как пропустить страницу
  • navigationActions — предложенные действия навигации
  • errorSignals — собранные ошибки (console, network, UI)

3. ContextualActionGenerator

Файл: contextual-action-generator.ts

Роль: Генерация действий на основе контекста

Входные данные:

  • PageContext — контекст страницы (URL, тип, элементы)
  • TestState — состояние теста (история, ошибки)
  • goal — цель тестирования

Выходные данные:

{ actions: DynamicAction[], // Массив действий reasoning: string, // Почему выбраны эти действия confidence: number, // Уверенность (0-1) nextExpectedPage: string // Ожидаемая следующая страница }

AI модели:

  • gpt-4o — генерация действий (по умолчанию)
  • gpt-4o-mini — fallback при ограничении бюджета

Новые возможности:

  • ✅ PII Masking — маскирование персональных данных в HTML перед отправкой в AI
  • ✅ Robust JSON Parsing — извлечение JSON из ответов AI с fallback стратегиями
  • ✅ Action Sanitization — валидация и очистка действий перед выполнением
  • ✅ Empty Page Detection — раннее обнаружение пустых страниц
  • ✅ Cycle Detection — обнаружение циклов перед генерацией

4. CommandExecutor

Файл: command-executor.ts

Роль: Выполнение Playwright команд

Поддерживаемые действия с Smart Locator:

Действие Smart Locator Self-Healing Smart Wait
click ✅ ✅ ✅
fill ✅ ✅ ✅
type ✅ ✅ ✅
select ✅ ✅ ✅
check/uncheck ✅ ✅ ✅
hover ✅ ✅ ✅
dblclick ✅ ✅ ✅

Flow выполнения команды:

1. getSmartLocator()

Анализирует элементы, выбирает лучший

2. waitFor({ state: 'visible' })

Ждёт видимости элемента

3. action.click/fill/etc()

Выполняет действие

4. При ошибке → Self-Healing

Повторяет с новым селектором

3. Полный Flow тестирования

1. ИНИЦИАЛИЗАЦИЯ

  • Создание browser context
  • Настройка abort controller
  • Инициализация cost manager

2. НАВИГАЦИЯ

  • goto(url, { waitUntil: 'domcontentloaded' })
  • waitForSPALoad() — ждёт network idle + interactive elements
  • Проверка статуса ответа

3. АНАЛИЗ СТРАНИЦЫ (IntelligentPageAnalyzer)

  • SPA Load Wait — ожидание полной загрузки SPA (network idle + interactive elements)
  • Modal Detection — обнаружение модальных окон (cookie banners, popups)
  • DOM Analysis — структура, элементы, формы
  • ✅ AI Selector Enhancement — улучшение DOM селекторов с помощью AI
  • Vision Analysis (GPT-4o, если нужно) — скриншот → понимание UI
  • ✅ Logic Analysis (GPT-4o-mini) — определение requiredActions, possibleActions, skipHints, navigationActions
  • ✅ Error Collection — сбор ошибок консоли, сети, UI
  • Результат: PageContext { url, pageType, elements, forms, warnings, requiredActions, possibleActions, skipHints, navigationActions, errorSignals }

4. ГЕНЕРАЦИЯ ДЕЙСТВИЙ (ContextualActionGenerator)

  • ✅ Проверка бюджета перед генерацией
  • ✅ Проверка пустых страниц (early exit)
  • ✅ Обнаружение циклов перед генерацией
  • AI (GPT-4o по умолчанию, GPT-4o-mini fallback) анализирует контекст
  • ✅ PII Masking — маскирование персональных данных в HTML
  • Генерирует действия для достижения цели
  • ✅ Sanitization — валидация и очистка действий
  • Результат: DynamicAction[] + reasoning + confidence

5. PRE-ACTION ANALYSIS (PreActionAnalyzer)

  • Проверка: элемент exists/visible/enabled?
  • Проверка состояния загрузки (loading)
  • ✅ Анализ формы (Form Intelligence) — если это submit кнопка
  • ✅ Обнаружение обязательных полей и ошибок валидации
  • ✅ Генерация prerequisite actions (smart fill sequence)
  • ✅ Сохранение baseline ошибок для сравнения после действия
  • Результат: canProceed + blockingFactors + suggestedActions + requiredFields

6. ВЫПОЛНЕНИЕ ДЕЙСТВИЯ (CommandExecutor)

a) getSmartLocator() — находит лучший элемент • Находит все элементы по селектору • Анализирует: tag, role, interactivity, visibility • Рассчитывает score для каждого • При неоднозначности → AI disambiguation • Возвращает лучший locator b) SmartWaitService — ждёт готовности • waitFor({ state: 'visible' }) • Адаптивная стратегия (fast/stable/network_idle/full) c) Выполнение: click/fill/select/etc d) При ошибке → Self-Healing • SelfHealingService.healSelector() • AI находит новый селектор • Повторяет действие

7. POST-ACTION ANALYSIS (PostActionAnalyzer)

  • ✅ Capture DOM Snapshot — снимок состояния DOM
  • ✅ Detect Changes — сравнение с предыдущим снимком
  • Что изменилось в DOM? (новые элементы, ошибки, модальные окна)
  • Появились ли autocomplete/suggestions/chips?
  • Появились ли модальные окна?
  • ✅ AI-driven Decision — AI решает нужны ли follow-up actions
  • ✅ Duplicate Prevention — предотвращение повторных кликов
  • Результат: needsFollowUp + followUpActions + reason + confidence

8. VALIDATION (ResultValidator)

  • Проверка expectedResult
  • Для fill/type: проверка input value
  • Для check: проверка checkbox state
  • Для select: проверка selected option

9. DECISION (ContextualActionGenerator.decideNextStep)

  • ✅ Проверка бюджета перед решением
  • ✅ Проверка циклов (cycle detection)
  • ✅ Проверка таймаута (max duration)
  • ✅ Проверка goalAchieved — цель достигнута?
  • ✅ Обнаружение blocking signals (captcha, 2fa, auth_required)
  • ✅ Оценка risk level (low/medium/high)
  • continue — продолжить тестирование
  • stop — цель достигнута или лимиты
  • wait_for_user — нужен input пользователя (с clarification request)
  • retry — повторить действие (с retryStrategy: wait/reload/navigate_back/choose_alternative_target/reduce_scope)
  • skip — пропустить и продолжить (goBack или goto startUrl)

  • Проверка отмены перед каждой итерацией

✅ Logic Analysis — Новый этап анализа

AI анализирует логику страницы и определяет необходимые действия.

  • requiredActions — действия, обязательные перед основными

✅ AI Selector Enhancement
