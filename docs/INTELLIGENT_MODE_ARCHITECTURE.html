1. Обзор системы

Intelligent Mode — это полностью автоматизированная система тестирования веб-приложений, использующая AI для анализа страниц, генерации действий и принятия решений.

Основной цикл работы:

analyze → understand → generate → execute → validate → decide → repeat

2. Файлы и их роли

1. IntelligentTestOrchestrator

Файл: intelligent-test-orchestrator.ts

Роль: Главный координатор всего процесса тестирования

Ключевые методы:

  • execute() — запуск теста
  • mainLoop() — основной цикл тестирования
  • analyzeCurrentPage() — анализ текущей страницы
  • generateAndExecuteActions() — генерация и выполнение действий
  • makeDecision() — решение о продолжении/остановке

2. IntelligentPageAnalyzer

Файл: intelligent-page-analyzer.ts

Роль: Анализ веб-страниц с помощью AI

Режимы анализа:

Режим Vision DOM Скорость Точность
fast ❌ ✅ Быстро Средняя
balanced ✅ (1 раз) ✅ Средне Высокая
full ✅ (всегда) ✅ Медленно Максимальная

Что анализирует:

  • Тип страницы (login, dashboard, checkout, etc.)
  • Доступные элементы (кнопки, формы, ссылки)
  • Модальные окна (cookie banners, popups)
  • Состояние SPA (ждёт полную загрузку)

3. ContextualActionGenerator

Файл: contextual-action-generator.ts

Роль: Генерация действий на основе контекста

Входные данные:

  • PageContext — контекст страницы (URL, тип, элементы)
  • TestState — состояние теста (история, ошибки)
  • goal — цель тестирования

Выходные данные:

{ actions: DynamicAction[], // Массив действий reasoning: string, // Почему выбраны эти действия confidence: number, // Уверенность (0-1) nextExpectedPage: string // Ожидаемая следующая страница }

AI модели:

  • gpt-4o-mini — быстрая генерация (по умолчанию)
  • gpt-4o — точная генерация (для сложных случаев)

4. CommandExecutor

Файл: command-executor.ts

Роль: Выполнение Playwright команд

Поддерживаемые действия с Smart Locator:

Действие Smart Locator Self-Healing Smart Wait
click ✅ ✅ ✅
fill ✅ ✅ ✅
type ✅ ✅ ✅
select ✅ ✅ ✅
check/uncheck ✅ ✅ ✅
hover ✅ ✅ ✅
dblclick ✅ ✅ ✅

Flow выполнения команды:

1. getSmartLocator()

Анализирует элементы, выбирает лучший

2. waitFor({ state: 'visible' })

Ждёт видимости элемента

3. action.click/fill/etc()

Выполняет действие

4. При ошибке → Self-Healing

Повторяет с новым селектором

3. Полный Flow тестирования

1. ИНИЦИАЛИЗАЦИЯ

  • Создание browser context
  • Настройка abort controller
  • Инициализация cost manager

2. НАВИГАЦИЯ

  • goto(url, { waitUntil: 'domcontentloaded' })
  • waitForSPALoad() — ждёт network idle + interactive elements
  • Проверка статуса ответа

3. АНАЛИЗ СТРАНИЦЫ (IntelligentPageAnalyzer)

  • Vision Analysis (GPT-4o) — скриншот → понимание UI
  • DOM Analysis — структура, элементы, формы
  • Modal Detection — cookie banners, popups
  • Результат: PageContext { url, pageType, elements, forms, warnings }

4. ГЕНЕРАЦИЯ ДЕЙСТВИЙ (ContextualActionGenerator)

  • AI (GPT-4o-mini) анализирует контекст
  • Генерирует действия для достижения цели
  • Результат: DynamicAction[] + reasoning + confidence

5. PRE-ACTION ANALYSIS (PreActionAnalyzer)

  • Проверка: элемент enabled/visible?
  • Нужны ли prerequisite actions?
  • Результат: canProceed + prerequisiteActions

6. ВЫПОЛНЕНИЕ ДЕЙСТВИЯ (CommandExecutor)

a) getSmartLocator() — находит лучший элемент • Находит все элементы по селектору • Анализирует: tag, role, interactivity, visibility • Рассчитывает score для каждого • При неоднозначности → AI disambiguation • Возвращает лучший locator b) SmartWaitService — ждёт готовности • waitFor({ state: 'visible' }) • Адаптивная стратегия (fast/stable/network_idle/full) c) Выполнение: click/fill/select/etc d) При ошибке → Self-Healing • SelfHealingService.healSelector() • AI находит новый селектор • Повторяет действие

7. POST-ACTION ANALYSIS (PostActionAnalyzer)

  • Что изменилось в DOM?
  • Появились ли autocomplete/suggestions?
  • Появились ли модальные окна?
  • Нужны ли follow-up actions?

8. VALIDATION (ResultValidator)

  • Проверка expectedResult
  • Для fill/type: проверка input value
  • Для check: проверка checkbox state
  • Для select: проверка selected option

9. DECISION (ContextualActionGenerator.decideNextStep)

  • continue — продолжить тестирование
  • stop — цель достигнута или лимиты
  • wait_for_user — нужен input пользователя
  • retry — повторить действие
  • skip — пропустить и продолжить

5. Конфигурация

interface IntelligentTestConfig { goal: string; // Цель тестирования startUrl: string; // URL для начала mode: 'full' | 'fast' | 'balanced'; // Режим анализа maxPages?: number; // Макс. страниц (default: 10) maxDuration?: number; // Макс. время (default: 5 мин) safetyLevel?: 'strict' | 'normal' | 'permissive'; hints?: TestHint[]; // Подсказки от пользователя credentials?: { // Для авторизации email?: string; password?: string; }; }

Пример использования:

const config: IntelligentTestConfig = { goal: "Зарегистрировать нового пользователя", startUrl: "https://example.com/register", mode: "balanced", maxPages: 10, maxDuration: 5 * 60 * 1000, // 5 минут safetyLevel: "normal", credentials: { email: "test@example.com", password: "securePassword123" } }; const orchestrator = new IntelligentTestOrchestrator(config, userId, testId); const result = await orchestrator.execute(browser, page);
