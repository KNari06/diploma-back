📦 Packages System

Package structure, dependencies, imports/exports, and module organization

← Back to Features

📋 Overview

Packages system manages module structure, dependencies, and imports/exports across the codebase.

Key Features:

  • Organized by feature/domain
  • Centralized exports via index files
  • Type-safe imports with path aliases
  • Clear separation of concerns
  • Reusable utilities and services

📁 Main Packages

agent/

Purpose: Intelligent testing agent and orchestration

Key Files:

  • intelligent-test-orchestrator.ts - Main orchestrator
  • intelligent-page-analyzer.ts - Page analysis
  • contextual-action-generator.ts - Action generation
  • pre-action-analyzer.ts - Pre-action analysis
  • post-action-analyzer.ts - Post-action analysis
  • playwright/ - Playwright integration
api/

Purpose: REST API endpoints and controllers

Structure: Each feature has its own folder with controller and route files

Examples: auth/, chat/, apiTest/, intelligentTest/, user/, project/

services/

Purpose: Business logic and reusable services

Sub-packages:

  • ai/ - AI services (vision, embeddings, etc.)
  • core/ - Core services (credits, pricing, etc.)
  • testing/ - Testing services (UI, API, etc.)
  • websocket/ - WebSocket bridge
  • auth/ - Authentication services
ai/prompts/

Purpose: Centralized AI prompts

Files:

  • index.ts - Central export
  • intent-and-chat-prompts.ts - Intent parsing, chat
  • test-plan-prompts.ts - Test plan generation
  • intelligent-testing-prompts.ts - Intelligent testing prompts
websocket/

Purpose: Real-time communication

Files:

  • server.ts - Socket.IO server setup
  • websocket.service.ts - Event emission service
  • handlers/ - Connection, subscription handlers
  • types.ts - Typed events
utils/

Purpose: Utility functions

Files:

  • logger.ts - Logging utility
  • error-handler.ts - Error handling
  • validation.ts - Validation helpers
  • playwrightParser.ts - Playwright code parsing
types/

Purpose: TypeScript type definitions

Files:

  • index.ts - Main types export
  • playwright.types.ts - Playwright types
  • notifications.types.ts - Notification types
config/

Purpose: Configuration files

Files:

  • env.ts - Environment variables
  • queues.ts - Queue configuration
  • swagger.ts - Swagger/OpenAPI config

🔗 Import Patterns

Path Aliases: Configured in tsconfig.json

  • @/ - Points to src/
  • @/api/ - API routes
  • @/services/ - Services
  • @/utils/ - Utilities
  • @/types/ - Types

Example Imports:

import { logger } from '@/utils/logger';
import { UserCreditsService } from '@/services/core/user-credits.service';
import { Prompts } from '@/ai/prompts';
import { AuthUser } from '@/types';
