📋 Overview

The Intelligent Testing Flow is the core system for autonomous UI testing. It uses AI to analyze pages, generate test actions, and execute them with comprehensive error handling and quality verification.

Key components include page analysis (Vision + DOM), contextual action generation, intelligent execution with pre/post-action analysis, and adaptive decision-making for test progression.
