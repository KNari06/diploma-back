AI prompts with versioning, changes tracking, and usage analytics

← Back to Features

📋 Overview

Prompts system manages all AI prompts used in the platform. All prompts are centralized in src/ai/prompts/index.ts for easy management and updates.

Key Features:

  • Centralized prompt management
  • Organized by logical categories
  • Context-aware prompts
  • Multilingual support (AI auto-detects language)
  • Version tracking and optimization

📝 Prompt Categories

1. Intent Parsing

buildIntentPrompt - Determines user's intention from natural language

Detects: platform_test, api_test, general_chat, needs_clarification

Extracts: scope, target, URL, API method, body, headers

File: intent-and-chat-prompts.ts

2. Chat/Conversation

buildChatSystemPrompt - System prompt for general conversations

Defines platform capabilities, communication style, multilingual support

File: intent-and-chat-prompts.ts

3. Approval Detection

buildApprovalDetectionPrompt - Detects if user approved/rejected test plan

Handles natural language, emojis, slang in any language

File: intent-and-chat-prompts.ts

4. API Test Plans

buildApiTestPlanPrompt - Generates detailed API test plan

Includes validation steps, expected status, headers, body, potential issues

File: test-plan-prompts.ts

5. UI Test Plans

buildTestPlanPrompt - Generates comprehensive UI test plan

Step-by-step flow, Playwright commands, duration estimate

File: test-plan-prompts.ts

6. API Fuzzing

buildApiFuzzingPrompt - Generates fuzzing scenarios for API testing

Edge cases, invalid inputs, boundary testing

File: test-plan-prompts.ts

7. Dynamic Questions

buildDynamicQuestionPrompt - Generates clarifying questions

Used when missing URL, unclear scope, need credentials

File: test-plan-prompts.ts

8. Intelligent Testing - Page Analysis

buildPageAnalysisPrompt - Analyzes page screenshot with Vision API

Identifies interactive elements, page type, layout, modals

File: intelligent-testing-prompts.ts

9. Intelligent Testing - Action Generation

buildActionGenerationPrompt - Generates test actions based on page context

Creates click, fill, wait, navigate actions with selectors

File: intelligent-testing-prompts.ts

10. Intelligent Testing - Next Step

buildNextStepPrompt - Decides next step in test execution

Returns: continue, stop, wait_for_user, retry, skip with confidence

File: intelligent-testing-prompts.ts

11. Intelligent Testing - Logic Analysis

buildLogicAnalysisPrompt - Analyzes page logic and flow

Identifies form validation, navigation patterns, state changes

File: intelligent-testing-prompts.ts

12. Intelligent Testing - Vision

buildVisionPrompt - Vision API prompt for screenshot analysis

Enhanced with DOM context, element properties, page structure

File: intelligent-testing-prompts.ts

13. URL Analysis

buildUrlAnalysisPrompt - Analyzes URL context and structure

Extracts domain, path, parameters, identifies page type

File: test-plan-prompts.ts

14. Custom Scope Strategy

buildCustomScopeStrategyPrompt - Generates custom testing strategy

Creates tailored approach based on user requirements

File: test-plan-prompts.ts

📁 File Structure

src/ai/prompts/index.ts - Central export file, re-exports all prompts

src/ai/prompts/intent-and-chat-prompts.ts - Intent parsing, chat, approval detection

src/ai/prompts/test-plan-prompts.ts - API/UI test plans, fuzzing, questions

src/ai/prompts/intelligent-testing-prompts.ts - Intelligent testing (page analysis, actions, vision)

src/ai/prompts/prompt-utils.ts - Utility functions for prompt building

🌍 Language Policy

All prompts are in English (for US market launch)

AI automatically detects user's language and responds accordingly

Supports: English, Russian, Spanish, Kazakh, and more

Context-first approach: Understands user's TRUE INTENT, not just keywords
