💳 Credits System

Credit allocation, deduction, limits, and subscription plan management

← Back to Features

📋 Overview

Credits system manages user credits, subscription plans, limits, and credit allocation/deduction for various operations.

Key Features:

  • Decimal credits support (0.5, 1.23, etc.)
  • Daily and monthly credit limits
  • Subscription plan management (Free, Pro, Ultra)
  • Credit transactions tracking
  • Automatic credit reset (daily/monthly)
  • Credit cost calculation for AI operations

🔧 Core Services

UserCreditsService

File: src/services/core/user-credits.service.ts

Methods:

  • getOrCreateUserCredits(userId) - Get or create user credits record
  • hasCredits(userId, amount) - Check if user has enough credits
  • deductCredits(userId, amount, description, metadata) - Deduct credits from balance
  • addCredits(userId, amount, description, metadata) - Add credits to balance
  • updateSubscription(userId, plan) - Update user subscription plan
PricingPlansService

File: src/services/core/pricing-plans.service.ts

Methods:

  • getAllPlans() - Get all active pricing plans
  • getPlanBySlug(slug) - Get plan by slug (free, pro, ultra)
  • getUserPlanInfo(userId) - Get user's plan with limits and usage
  • assignPlanToUser(userId, planId) - Assign plan to user
  • checkCreditLimits(userId, amount) - Check if user can use credits
  • useCredits(userId, amount) - Use credits with limit checking
CreditCostTrackerService

File: src/services/core/credit-cost-tracker.service.ts

Methods:

  • trackAICall(model, inputTokens, outputTokens) - Track AI call and calculate credits
  • calculateTestCost(testType, operations) - Calculate total cost for test
  • deductCreditsForTest(deduction) - Deduct credits for test execution

📊 Database Schema

user_credits table:

  • user_id (UUID) - Foreign key to users
  • credits_balance (NUMERIC) - Current balance (supports decimals)
  • subscription_plan (TEXT) - Current plan (free, pro, ultra)
  • total_used (NUMERIC) - Total credits used
  • created_at, updated_at

credit_transactions table:

  • user_id (UUID)
  • amount (NUMERIC) - Positive for additions, negative for deductions
  • type (TEXT) - usage, purchase, refund, etc.
  • description (TEXT)
  • metadata (JSONB) - Additional data
  • created_at

pricing_plans table:

  • id, name, slug, description
  • price (NUMERIC) - NULL for free plan
  • credits_per_month (INTEGER) - -1 for unlimited
  • credits_per_day (INTEGER) - NULL if no daily limit
  • features (TEXT[]), limitations (TEXT[])

💰 Credit Calculation

AI Operations: Credits calculated based on token usage

  • Input tokens: Model-specific rate
  • Output tokens: Model-specific rate
  • Vision API: Additional cost per image

Test Types:

  • Intelligent Test: Base cost + AI operations
  • Standard Test: Base cost per browser
  • API Test: Lower cost, no browser overhead

Decimal Support: All credit amounts support decimals (0.5, 1.23, etc.)
